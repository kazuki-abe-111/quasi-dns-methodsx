Quasi-DNS with chemical kinetics for a single multiple-injection burner element
under stable lean conditions for future gas turbine applications
===============================================================================

Supporting materials for the MethodsX manuscript:

Kazuki Abe, Youhi Morii, and Kaoru Maruta,
"Quasi-DNS with chemical kinetics for a single multiple-injection burner
element under stable lean conditions for future gas turbine applications",
MethodsX, submitted.


Contents
--------

case/
    OpenFOAM case files, including initial and boundary conditions,
    operating conditions, and numerical settings.

mesh/
    Pointwise project file used to generate the computational mesh.

data/
    Selected representative results and processed data.

scripts/
    Selected scripts for data processing and figure generation.


Scope
-----

This repository provides the numerical setup, including the geometry,
boundary conditions, operating conditions, and numerical settings. The
computational mesh is provided as a Pointwise project file in the `mesh/`
directory. The full OpenFOAM `constant/polyMesh` directory is not included
because of its size. Selected representative results are also provided.
